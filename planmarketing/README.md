# Landing · Plan de Marketing 2027

Landing estática de estilo editorial tipo WordPress, construida con HTML, CSS y JavaScript sin dependencias de compilación.

## Estructura

- `index.html`: contenido y estructura semántica.
- `assets/css/styles.css`: sistema visual responsive de UADEN.
- `assets/js/main.js`: menú móvil, carrusel accesible, módulos interactivos, navegación, progreso de lectura y cuenta regresiva.
- `assets/images/`: logotipos, retrato y diez fotografías generadas para la landing.
- `assets/images/prompts/`: prompts exactos de las imágenes generadas.
- `PLAN DE MARKETING 2027.pdf`: folleto oficial actualizado y archivo descargable.

## Publicación

La carpeta completa puede subirse a cualquier hosting estático. También puede integrarse como plantilla personalizada de WordPress conservando la estructura del HTML y separando encabezado, contenido y pie en los archivos del tema.

## Datos editables

Los enlaces de WhatsApp, teléfonos, fecha, horarios y precios están en `index.html`. La fecha límite del contador y la velocidad del carrusel se configuran en `assets/js/main.js`. El botón “Descargar PDF” entrega directamente el folleto incluido en la carpeta.
