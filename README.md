# Proyectouaden

Landing principal index.html y landing pages secundarias en sus directorios actuales. HTML, CSS, JavaScript y recursos se conservan para edición local.

El flujo de Hostinger está limitado a HTML y en modo simulación. No modifica WordPress, PHP, bases de datos ni .htaccess. Ver DESPLIEGUE.md y deploy/allowlist.json para rutas permitidas, configuración pendiente, GitHub Secrets y reversión.

WordPress permanece independiente en Hostinger y está excluido de Git. Las copias locales campuss/, preuaden/, registro/ y uadenw/ no forman parte del despliegue.

Consultar AUDITORIA.md para la revisión anterior y sus límites.
